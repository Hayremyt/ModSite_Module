Приоритет источников обновлений

Проверка идёт сверху вниз: мод ищется на первом источнике; если его там нет (проект удалён, источник недоступен или у мода нет метаданных), установленный файл ищется по хэшу на следующем. Найденный на приоритетном источнике файл перепривязывает мод к нему.

Поведение модпака

Игнорируемые файлы по категориям

Шаблоны как в .gitignore — по одному на строку. Подходящие файлы и папки модуль не трогает: не показывает «лишними», не импортирует и не тратит на них запросы к Modrinth/CurseForge. Например: .index (папка Sinytra Connector), *.tmp, cache/, !keep.jar — исключение из игнора. # — комментарий.

Предложения и поиск

Без права предлагатьлогины, которым кнопка «Предложить» недоступна

    Вывод в консоль сервера

    off — модуль молчит полностью; error — только ошибки; warn — ошибки и предупреждения (по умолчанию); all — весь вывод, включая отладку синхронизации. Применяется сразу и не влияет на файл аудита.

    Темы оформления сайта

    У каждой темы — светлый и тёмный вариант: игроки, наблюдатели и админы выбирают подходящий в меню «Тема» в топбаре; выбор сохраняется в браузере. Тема и вариант по умолчанию — для тех, кто ещё ничего не выбрал.

    Встроенные темы

    Выключенная тема скрыта у всех: у игроков, наблюдателей и администраторов. Выключить можно любую, но хотя бы одна должна остаться (или добавьте свою).

    Свои темы

    Своя тема — название, шрифт, углы и по семь цветов на светлый и тёмный вариант; остальные тона сайт выводит сам. Доступна всем так же, как встроенные. Максимум — 16.

                        Бекапы профиля
                        
                    
        
                    
        
                        Бекап — настоящий .mrpack (формат Modrinth): контент с привязкой к Modrinth/CurseForge хранится ссылками и скачивается заново при восстановлении; остальное — в overrides внутри архива.
                    
        
                    
        
                        Чужой .mrpack (в том числе пакет другой сборки): положите файл в config/ModsSite/backups/<профиль>/ на сервере — он появится в списке и восстановится как обычный бекап.
